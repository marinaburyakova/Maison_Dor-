##  About The Project

**Maison Doré** is a premium e-commerce website for a luxury clothing boutique. This project is a fully functional Single Page Application (SPA) featuring modern design, responsive layout, and interactive elements.

###  Key Features

-  **Elegant Design** — Minimalist, luxury interface with gold accents
-  **Fully Responsive** — Perfect display on all devices
-  **Shopping Cart** — Add, remove, and update product quantities
-  **Favorites/Wishlist** — Save your favorite items
-  **Authentication** — Login and registration via modal window
-  **Search & Filtering** — Convenient product search and category filters
-  **Video Background** — Stunning video hero section on the homepage
-  **Newsletter Subscription** — Email subscription form
 Technologies

### Frontend
- **React 18** — UI library
- **React Router v6** — Application routing
- **Vite** — Fast build tool and development server
- **CSS-in-JS** — Component styling

### State Management
- **React Context API** — Global state management (cart, favorites, authentication)
- **Custom Hooks** — Reusable logic

### Additional Libraries
- **react-icons** — Icon library
- **react-helmet-async** — SEO meta tags management
- **axios** — HTTP requests (for future backend)
