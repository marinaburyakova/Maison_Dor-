# Интернет-магазин Maison Doré - премиальная одежда из Италии.

Современное веб-приложение интернет-магазина с полным функционалом корзины, избранного, аутентификации и маршрутизацией.
## Обзор

Это полнофункциональное React-приложение электронной коммерции, построенное с использованием современных подходов: контекстное управление состоянием, ленивая загрузка, защищенные маршруты и гибкая система маршрутизации.

## Ключевые возможности

###  Основной функционал
- **Каталог товаров**: Просмотр всех товаров с фильтрацией
- **Детальная страница**: Подробная информация о товаре
- **Корзина**: Добавление/удаление товаров, изменение количества
- **Избранное**: Сохранение понравившихся товаров
- **Оформление заказа**: Полный процесс оформления
- **Аутентификация**: Регистрация и вход в систему

###  Безопасность
- Защищенные маршруты для авторизованных пользователей
- Гостевая маршрутизация для неавторизованных
- Защита от несанкционированного доступа

###  Производительность
- Ленивая загрузка компонентов (Code Splitting)
- Оптимизированная маршрутизация
- Кэширование контекста

## Технический стек

| Технология | Назначение |
|------------|------------|
| **React 18** | Основной фреймворк |
| **React Router v6** | Маршрутизация |
| **Context API** | Управление состоянием |
| **React.lazy + Suspense** | Ленивая загрузка |
| **HashRouter** | Клиентская маршрутизация |


##  Производительность

### Оптимизации

1. **Lazy Loading**: Компоненты загружаются по требованию
2. **Code Splitting**: Webpack автоматически разделяет код
3. **Suspense**: Плавные состояния загрузки
4. **Context Optimization**: Предотвращение лишних ререндеров

### Метрики

- **Initial Load**: ~150KB (gzipped)
- **Time to Interactive**: < 2s
- **Lighthouse Performance**: > 90

### Создание нового контекста

1. Создать файл в `context/`
2. Определить провайдер и хук
3. Обернуть компоненты в провайдер
4. Использовать хук в компонентах

##  Примечания для разработчиков

- **HashRouter** используется для поддержки SPA без серверного роутинга
- Все контексты обернуты во вложенные провайдеры для правильного доступа
- **ProtectedRoute** и **GuestRoute** используют `replace` для предотвращения возврата
- **Suspense** с **LoadingSpinner** обеспечивает плавный UX
